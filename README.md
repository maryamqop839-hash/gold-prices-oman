# الذهب العُماني - لوحة متابعة أسعار الذهب

تطبيق ويب من صفحة واحدة (Single Page Application) لمتابعة أسعار الذهب في سلطنة عُمان، مبني باستخدام **Angular** و**Tailwind CSS**، بواجهة عربية كاملة واتجاه من اليمين إلى اليسار (RTL).

يتيح التطبيق للمستخدم عرض أسعار الذهب اليومية لكل عيار، وتقدير قيمة الذهب حسب الوزن، ومتابعة حركة الأسعار خلال آخر 30 يومًا بالرسم البياني والجدول.

> **ملاحظة:** جميع الأسعار المعروضة بيانات تجريبية لأغراض التدريب، ولا يوجد ربط بأي API أو Backend حقيقي.

## المميزات

- عرض أسعار الذهب لليوم لعيارات 18 و21 و22 و24 قيراط.
- حاسبة لتقدير القيمة الإجمالية حسب العيار والوزن بالغرام، مع حالة فارغة قبل إجراء الحساب.
- رسم بياني خطي (SVG Polyline) لتغير الأسعار خلال آخر 30 يومًا، مع أزرار للتبديل بين العيارات.
- بطاقات ملخصة تعرض السعر الحالي وأعلى سعر وأقل سعر، وملخص يقارن السعر الحالي بالسابق ومقدار التغير.
- جدول سجل الأسعار لآخر 30 يومًا بألوان صفوف متناوبة وتمرير أفقي في الشاشات الصغيرة.
- شريط تنقل ثابت (Sticky) بروابط تنتقل إلى أقسام الصفحة.
- تصميم متجاوب يعمل على الكمبيوتر والتابلت والجوال.

## التقنيات المستخدمة

- **Angular 22:** هو إطار العمل الأساسي للمشروع. اعتمدنا فيه على المكوّنات المستقلة (Standalone Components)، فكل جزء من الصفحة له ملفاته الخاصة ويمكن إعادة استخدامه.
- **TypeScript:** لغة البرمجة المستخدمة، وتساعد في اكتشاف الأخطاء مبكرًا. استخدمنا `interface` لتحديد شكل بيانات الأسعار.
- **Tailwind CSS:** مكتبة تنسيق نكتب فيها الكلاسات مباشرة داخل HTML، وبها بنينا التصميم المتجاوب وألوان الواجهة.
- **Signals و computed:** نستخدمها لإدارة الحالة، فعند تغيير العيار في الرسم البياني تتحدث الأرقام والرسم تلقائيًا دون إعادة حساب يدوي.
- **SVG:** رسمنا به الخط البياني مباشرة دون الحاجة لمكتبة خارجية.

## المكوّنات

### Header (شريط التنقل)

يبقى ثابتًا في أعلى الصفحة أثناء التمرير. يحتوي على شعار الموقع، وروابط تنقل سريعة إلى الأقسام، وشارة صغيرة توضح أن البيانات تجريبية.

### Hero (الواجهة الرئيسية)

أول ما يراه المستخدم عند فتح الصفحة. خلفيته متدرجة، وفيه مسار التنقل والعنوان والوصف، وشريط في الأسفل يعرض تاريخ آخر تحديث ومعلومات السوق والعملة.

### Prices (قسم الأسعار)

يجمع أسعار اليوم من الـ Service ويعرضها في شبكة متجاوبة، بطاقة لكل عيار.

### PriceCard (بطاقة السعر)

مكوّن صغير قابل لإعادة الاستخدام، يستقبل بيانات عيار واحد ويعرضها. يُستخدم أربع مرات بدل كتابة أربع بطاقات منفصلة.

### Calculator (حاسبة الذهب)

يختار المستخدم العيار ويدخل الوزن بالغرام ثم يضغط "احسب"، فتظهر بطاقة بالقيمة الإجمالية التقديرية. وقبل الحساب تظهر رسالة توضح الخطوات (حالة فارغة).

### Chart (الرسم البياني)

يعرض حركة السعر خلال آخر 30 يومًا بخط مرسوم بـ SVG. يتبدل العيار بأزرار، وتظهر معه بطاقات السعر الحالي وأعلى سعر وأقل سعر، وملخص للمقارنة مع السعر السابق.

### HistoryTable (جدول السجل)

جدول بآخر 30 يومًا وأسعار العيارات الأربعة لكل يوم، بصفوف متناوبة الألوان وتمرير أفقي في الشاشات الصغيرة.

### Footer (التذييل)

يعرض اسم الموقع ووصفه المختصر وحقوق النشر.

## تدفق البيانات

كل البيانات تأتي من مكان واحد هو الـ Service المسمى `GoldData`:

1. يحتفظ `GoldData` بسعر الغرام لعيار 24 كقيمة تجريبية ثابتة، ويحسب باقي العيارات بالنسبة `(سعر 24 × العيار) / 24`.
2. المكوّنات تحصل على الـ Service عن طريق `inject(GoldData)`.
3. `Prices` يجلب أسعار اليوم ثم يمرر كل سعر إلى `PriceCard` عبر `[data]="item"`.
4. `Calculator` يستدعي `getPriceByKarat` ويضرب النتيجة في الوزن.
5. `Chart` و`HistoryTable` يستدعيان `getHistory` للحصول على أسعار آخر 30 يومًا.

ميزة هذا الأسلوب أن البيانات لو تغيرت (مثلًا عند الربط بـ API لاحقًا) يكفي تعديل الـ Service فقط دون المساس بالمكوّنات.

## التثبيت والتشغيل

**المتطلبات:** Node.js وnpm، وAngular CLI:

```bash
npm install -g @angular/cli
```

**1. تحميل المشروع:**

```bash
git clone https://github.com/maryamqop839-hash/gold-prices-oman.git
cd gold-prices-oman
```

**2. تثبيت المكتبات:**

```bash
npm install
```

**3. تشغيل المشروع:**

```bash
ng serve
```

**4. افتحي المتصفح على:** <http://localhost:4200>

**بناء نسخة للإنتاج:**

```bash
ng build
```
