# الذهب العُماني - لوحة متابعة أسعار الذهب

تطبيق ويب من صفحة واحدة (Single Page Application) لمتابعة أسعار الذهب في سلطنة عُمان، مبني باستخدام Angular وTailwind CSS. يدعم اللغتين العربية والإنجليزية (مع انعكاس اتجاه الصفحة RTL/LTR)، والوضعين الفاتح والداكن، بتصميم عصري بلمسات ذهبية وتأثيرات زجاجية.

يتيح التطبيق للمستخدم عرض أسعار الذهب اليومية لكل عيار، وتقدير قيمة الذهب حسب الوزن، ومتابعة حركة الأسعار خلال آخر 30 يومًا بالرسم البياني والجدول.

ملاحظة: جميع الأسعار المعروضة بيانات تجريبية لأغراض التدريب، ولا يوجد ربط بأي API أو Backend حقيقي.

## المميزات

عرض أسعار الذهب لليوم لعيارات 18 و21 و22 و24 قيراط، مع شريط نقاء لكل عيار.
حاسبة لتقدير القيمة الإجمالية حسب العيار والوزن بالغرام، مع أوزان سريعة، ورسالة تنبيه، وحالة فارغة قبل إجراء الحساب.
رسم بياني مساحي (SVG) لتغير الأسعار خلال آخر 30 يومًا، مع أزرار للتبديل بين العيارات ومؤشر تفاعلي يعرض سعر كل يوم.
بطاقات ملخصة تعرض السعر الحالي وأعلى سعر وأقل سعر، وملخص يقارن السعر الحالي بالسابق ومقدار التغير ونسبته.
جدول سجل الأسعار لآخر 30 يومًا بألوان صفوف متناوبة وتمرير أفقي في الشاشات الصغيرة، يعرض 7 أيام افتراضيًا مع زر لعرض الكل.
دعم لغتين: العربية والإنجليزية، مع انعكاس اتجاه الصفحة والرسم البياني تلقائيًا.
وضع فاتح وداكن: يتبع إعداد الجهاز افتراضيًا، ويتذكر اختيار المستخدم.
شريط تنقل زجاجي ثابت (Sticky) بروابط تنتقل إلى أقسام الصفحة.
تصميم متجاوب يعمل على الكمبيوتر والتابلت والجوال.

## التقنيات المستخدمة

Angular 22: هو إطار العمل الأساسي للمشروع. اعتمدنا فيه على المكوّنات المستقلة (Standalone Components)، فكل جزء من الصفحة له ملفاته الخاصة ويمكن إعادة استخدامه.
TypeScript: لغة البرمجة المستخدمة، وتساعد في اكتشاف الأخطاء مبكرًا. استخدمنا interface لتحديد شكل بيانات الأسعار.
Tailwind CSS: مكتبة تنسيق نكتب فيها الكلاسات مباشرة داخل HTML. عرّفنا فيها نظام ألوان خاص (gold وink) عبر @theme، وفعّلنا الوضع الداكن بالكلاس dark.
Signals و computed و effect: نستخدمها لإدارة الحالة، فعند تغيير العيار أو اللغة أو الثيم تتحدث الواجهة تلقائيًا دون إعادة حساب يدوي. وتُستخدم effect لتحديث lang وdir والكلاس dark في وسم <html>.
SVG: رسمنا به الخط البياني مباشرة دون الحاجة لمكتبة خارجية.
خط Tajawal: خط عربي حديث يدعم الإنجليزية أيضًا.

## المكوّنات

### Header (شريط التنقل)

شريط زجاجي عائم يبقى ثابتًا في أعلى الصفحة أثناء التمرير. يحتوي على شعار الموقع، وروابط تنقل سريعة إلى الأقسام، وشارة توضح أن البيانات تجريبية، وزر لتبديل اللغة، وزر لتبديل الوضع الفاتح والداكن.

### Hero (الواجهة الرئيسية)

أول ما يراه المستخدم عند فتح الصفحة. خلفيته بتوهج ذهبي وكرات ضوء بحركة هادئة، وفيه مسار التنقل والعنوان والوصف وأزرار الانتقال للأقسام، وبطاقة زجاجية تعرض سعر عيار 24، وحبوب معلومات تعرض تاريخ آخر تحديث والسوق والعملة.

### Prices (قسم الأسعار)

يجمع أسعار اليوم من الـ Service ويعرضها في شبكة متجاوبة، بطاقة لكل عيار.

### PriceCard (بطاقة السعر)

مكوّن صغير قابل لإعادة الاستخدام، يستقبل بيانات عيار واحد ويعرضها. يُستخدم أربع مرات بدل كتابة أربع بطاقات منفصلة. تُميَّز بطاقة عيار 24 بإطار ذهبي وشارة، ويظهر في كل بطاقة شريط نقاء يُحسب من (العيار ÷ 24).

### Calculator (حاسبة الذهب)

يختار المستخدم العيار بالأزرار ويدخل الوزن بالغرام (أو يختار وزنًا سريعًا) ثم يضغط "احسب"، فتظهر بطاقة ذهبية بالقيمة الإجمالية التقديرية وتفصيل الحساب. وقبل الحساب تظهر رسالة توضح الخطوات (حالة فارغة)، وإذا أُدخل وزن غير صالح تظهر رسالة تنبيه.

### Chart (الرسم البياني)

يعرض حركة السعر خلال آخر 30 يومًا برسم مساحي SVG. يتبدل العيار بأزرار، وتظهر معه بطاقات السعر الحالي وأعلى سعر وأقل سعر، وملخص للمقارنة مع السعر السابق. وعند تحريك المؤشر على الرسم يظهر سعر وتاريخ كل يوم. يتغير اتجاه الرسم مع اللغة: الأقدم على اليمين في العربية وعلى اليسار في الإنجليزية.

### HistoryTable (جدول السجل)

جدول بآخر 30 يومًا وأسعار العيارات الأربعة لكل يوم، بصفوف متناوبة الألوان وتمرير أفقي في الشاشات الصغيرة. يعرض 7 أيام افتراضيًا ويتوسع بزر لعرض الأيام كلها، ويُميَّز صف اليوم بشارة.

### Footer (التذييل)

يعرض الشعار ووصف الموقع وروابط سريعة وحقوق النشر، وتُحسب السنة تلقائيًا.

## تدفق البيانات

كل البيانات تأتي من مكان واحد هو الـ Service المسمى GoldData:

يحتفظ GoldData بسعر الغرام لعيار 24 كقيمة تجريبية ثابتة، ويحسب باقي العيارات بالنسبة (سعر 24 × العيار) / 24.
المكوّنات تحصل على الـ Service عن طريق inject(GoldData).
Prices يجلب أسعار اليوم ثم يمرر كل سعر إلى PriceCard عبر [data]="item".
Calculator يستدعي getPriceByKarat ويضرب النتيجة في الوزن.
Chart وHistoryTable يستدعيان getHistory للحصول على أسعار آخر 30 يومًا.

ميزة هذا الأسلوب أن البيانات لو تغيرت (مثلًا عند الربط بـ API لاحقًا) يكفي تعديل الـ Service فقط دون المساس بالمكوّنات.

## التثبيت والتشغيل

**المتطلبات:** Node.js وnpm، وAngular CLI:

```bash
npm install -g @angular/cli
```

**1. تحميل المشروع:**

```bash
git clone https://github.com/maryamqop839-hash/gold-prices-oman.git
cd gold-prices-oman
```

**2. تثبيت المكتبات:**

```bash
npm install
```

**3. تشغيل المشروع:**

```bash
ng serve
```

**4. افتحي المتصفح على:** <http://localhost:4200>

**بناء نسخة للإنتاج:**

```bash
ng build
```
